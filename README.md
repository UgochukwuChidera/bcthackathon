# BCT Hackathon: Review Generator & Recommendation Agent

This space hosts two agents:
1. **Review Generator (Task A):** A persona-driven agent that generates authentic, human-sounding product reviews (with Nigerian slang support).
2. **Recommendation Agent (Task B):** A cross-domain recommender that suggests products, restaurants, or books based on user personas.

## Setup
To run this app, you need to set the `OPENROUTER_API_KEY` secret in your environment.
